GitHub 첫 레포 만들기

STAR 기법으로 정리한 학습 기록

S

Situation · 상황

프로젝트 결과물을 버전 관리하고 공유해야 했지만, Git/GitHub 사용 경험이 없어 전체 흐름을 몰랐다.

T

Task · 과제

GitHub에서 새 저장소를 만들고 로컬 프로젝트를 업로드하는 전체 과정을 직접 확인하고 싶었다.

A

Action · 행동

  • git init 로컬 저장소 초기화
  • git remote add origin 원격 연결
  • git add . / git commit
  • git push -u origin main
R

Result · 결과

생성 → 초기화 → 연결 → 커밋 → 푸시의 전체 흐름을 이해했고, 커밋과 푸시의 차이를 명확히 알게 되었다.
