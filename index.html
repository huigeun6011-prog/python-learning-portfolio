2026.10.27 폴더 만들기와 경로 이동 ▾
S

Situation · 상황

터미널에서 폴더를 만들고 다른 폴더로 이동해야 했는데, 명령어들이 영어 약자라 의미가 잘 와닿지 않아 헷갈렸다.

T

Task · 과제

pwd, ls, cd, mkdir이 각각 무슨 약자이고 어떤 역할을 하는지 확인하고 싶었다.

A

Action · 행동

  • pwd → Print Working Directory : 현재 위치한 경로 출력
  • ls → List : 현재 폴더의 파일/폴더 목록 보기
  • cd → Change Directory : 다른 폴더로 이동
  • mkdir → Make Directory : 새 폴더 생성
R

Result · 결과

각 명령어가 영어 단어의 앞글자 조합이라는 걸 알게 되었고, 약자만 알아도 역할이 자연스럽게 떠오르게 되었다.

2026.10.28 파이썬 가상환경 구축과 pip install ▾
S

Situation · 상황

파이썬 프로젝트를 진행하려는데, 패키지를 전역(global)에 설치하면 다른 프로젝트와 버전이 충돌할 것 같아 걱정이었다.

T

Task · 과제

프로젝트별로 독립된 가상환경(venv)을 만들고, 그 안에서 pip install로 패키지를 설치하는 흐름을 익히고 싶었다.

A

Action · 행동

  • python -m venv venv → 가상환경 폴더 생성
  • source venv/bin/activate (macOS/Linux) 또는 venv\Scripts\activate (Windows) → 가상환경 활성화
  • pip install <패키지명> → 가상환경 안에 패키지 설치
  • pip list → 설치된 패키지 확인
  • deactivate → 가상환경 종료
R

Result · 결과

가상환경을 활성화한 상태에서만 pip install이 해당 환경에 적용된다는 것을 알게 되었다. 프롬프트 앞에 (venv)가 붙으면 활성화된 상태라는 표시라는 점도 확인했다. 프로젝트마다 환경을 분리하면 버전 충돌을 피할 수 있다는 걸 이해했다.

2026.10.29 Flask와 schedule이 뭔지 찾아보다 NEW ▾
S

Situation · 상황

과제에서 Flask랑 schedule을 설치해보라고 했는데, 이름만 들어봤지 정확히 뭐 하는 건지 몰랐다.

T

Task · 과제

궁금해서 직접 찾아보기로 했다. 각각 어떤 역할을 하고, 대충 어떻게 쓰는 건지만 알아보는 게 목표였다.

A

Action · 행동

  • Flask : 파이썬으로 웹페이지를 만들 때 쓰는 도구. 주소(/)랑 그 주소에서 보여줄 코드를 연결해주는 방식이고, HTML 파일도 같이 불러올 수 있다는 걸 알게 됐다.
  • schedule : 정해진 시간마다 내 코드를 자동으로 실행시켜 주는 도구. schedule.every(10).seconds.do(함수) 처럼 "10초마다 이 함수 실행" 식으로 읽히듯이 쓸 수 있다는 게 신기했다.
R

Result · 결과

Flask는 웹사이트를 만들어주는 도구, schedule은 시간 맞춰 코드를 실행해주는 도구라는 차이를 알게 됐다. 아직 직접 써보진 않았지만, 과제에서 왜 이 둘을 설치하라고 했는지 감이 잡혔다.
